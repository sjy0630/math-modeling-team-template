# 比赛前两小时

目标不是立刻选出“高级模型”，而是形成统一题意、数据事实和第一个可运行闭环。

## 0–45 分钟：独立拆题

- 三人各自阅读题目和附件说明；
- 分别填写 `templates/01_individual_problem_analysis.md`；
- 暂不搜索完整解法，避免全队被第一个模型名锚定。

## 45–75 分钟：数据体检

- 列出每个文件的行列数、字段、单位、日期范围和主键；
- 检查缺失、重复、异常值及表间连接损失；
- 把确定事实与解释性猜测分开记录。

## 75–105 分钟：合并问题树

- 使用 `templates/02_team_problem_tree.md` 比较三份理解；
- 对每一问写清输入、输出、目标、约束、假设和验证；
- 未达成一致的口径进入 `decision_log.md`，不靠口头模糊过去。

## 105–120 分钟：启动 baseline

- 只选一个最小闭环；
- 指定第一责任人和复核人；
- 约定一个能由脚本生成的表、图或指标；
- 设定下一次同步时间和停止条件。
