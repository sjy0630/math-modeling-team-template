# 提交检查表

## 题意与模型

- [ ] 每一问都有明确输出，且正文实际回答了它。
- [ ] 决策变量、参数、目标函数和约束定义一致。
- [ ] 所有补充假设都有理由，并说明可能造成的偏差。
- [ ] baseline、改进模型和选择理由能对应起来。

## 数据与代码

- [ ] 单位、时间范围、缺失值和异常值口径全篇一致。
- [ ] 没有未来信息泄漏、主键意外重复或连接丢失。
- [ ] 关键图表与数字可由提交的代码重新生成。
- [ ] 代码不含本机绝对路径、账号、密钥或无关数据。

## 验证

- [ ] 有样本外、回测、交叉验证或合理的替代检验。
- [ ] 优化/仿真结果满足全部硬约束。
- [ ] 对关键参数做了敏感性或稳健性分析。
- [ ] 明确写出模型失效条件与限制。

## 论文与材料

- [ ] 摘要包含方法、关键数值结果、验证和结论。
- [ ] 图表有编号、标题、坐标、单位和正文解释。
- [ ] 符号表、公式、图表和代码使用同一口径。
- [ ] 参考资料可追溯，AI 使用按当届规则披露。
- [ ] 文件命名、匿名要求、页数与支撑材料符合当届官方规则。
