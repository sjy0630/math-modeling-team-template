# 数据目录

```text
data/
├── raw/        # 官方原始文件，只读
├── interim/    # 清洗、连接、聚合后的中间文件
└── processed/  # 模型正式读取的输入表
```

数据文件默认不进入 Git。队伍应通过私有渠道共享附件，并在下表记录来源和 SHA-256，确保三人使用同一版本。

| 文件 | 来源 | SHA-256 | 粒度/单位 | 备注 |
| --- | --- | --- | --- | --- |
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

任何脚本都不得覆盖 `raw/` 中的文件。可再生数据写入 `interim/` 或 `processed/`。
